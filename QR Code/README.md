# QR Code Extended Training
### Required
- Python 3.x+
- Pandas (`pip install pandas`)
- SkLearn (`pip install sklearn`)
- Jupyter Notebook

### Purpose
Convert the datasets of *.csv* to QR Code images in *.png* format. To then process and analyse the results and compare to the original *.csv* text format.

## Dataset
The data-set for this process and analysis is the same two *.csv* files used in the original context, converted using `convertToQR.py` to a *.png* format. It is then processed and analyised.

## Outcome
If meeting the required metrics of the analysis (in comparision to the text version), this dataset can be used to implement a new feature to the over-arching project, allowing users in the front end to either scan or upload QR Code images and get a result back.
